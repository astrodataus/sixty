# Sixty

The next sixty days of every community, on one page, with the reason attached. A multifamily portfolio ranked by what needs attention today, drilling from the portfolio to a community to a single unit and lease, where every total is the sum of the rows beneath it.

Kettle Moraine Residential is an invented company. All 40 communities, 5,680 units and every figure on the page are synthetic, generated once from a seed. Nothing here reads from a live system.
